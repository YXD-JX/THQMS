# 前后端可视化系统分析与解决方案

---

## 1. 项目架构总览

本系统采用前后端分离架构，前端基于 Vue3 + Three.js 实现 3D 热力图动态可视化，后端建议采用 Node.js + Express + SQLite（或 JSON 文件）实现参数与测量数据的持久化与 API 服务。

```
┌─────────────┐      HTTP API      ┌─────────────┐
│   前端 Vue  │ <———————→ │   后端 Node │
│  Heatmap3D  │                  │   Express   │
└─────────────┘                  └─────────────┘
```

---

## 2. 前端核心流程

- 参数与测量数据通过 Pinia Store (`lab.ts`) 管理。
- 3D 热力图组件 (`Heatmap3D.vue`) 负责渲染、交互与仿真。
- 支持自动仿真与后端数据对接两种模式。
- 主要技术点：
  - Three.js 网格渲染与颜色映射
  - 响应式数据流（Vue + Pinia）
  - 异常检测与提示

### 代码片段示例

```typescript
// 获取参数与测量
const lab = useLabStore()
const { params } = storeToRefs(lab)
// 渲染网格并根据测量值动态着色
function updateColors() {
  for (const cell of cells) {
    const p = params.value.find(x => x.id === cell.paramId)
    const v = valueAt(cell.paramId, cell.index)
    const col = colorFor(p, v)
    cell.mesh.material.color.copy(col)
  }
}
```

## 3. 后端 API 设计

建议接口：

- `GET /params`：获取参数列表
- `GET /measurements?paramId=...&limit=...`：获取测量历史
- `POST /measurements`：上传新测量
- `GET /anomalies`：获取异常列表

### 示例响应

```json
// GET /params
[
  { "id": "cu", "name": "铜离子浓度", "unit": "g/L", "target": 45, "lcl": 40, "ucl": 50 },
  ...
]
```

---

## 4. 前后端对接流程

1. 前端通过 axios/fetch 请求后端 API，获取参数与测量数据。
2. Pinia Store 负责数据同步与状态管理。
3. 用户可切换仿真/真实数据模式。
4. 异常检测后可推送通知或报警。

### 伪代码流程

```typescript
async function fetchParams() {
  const res = await fetch('/api/params')
  lab.params = await res.json()
}
async function fetchMeasurements(paramId) {
  const res = await fetch(`/api/measurements?paramId=${paramId}`)
  lab.meas[paramId] = await res.json()
}
```

## 5. 可视化效果与交互

- 3D 网格热力图，颜色映射参数状态（低于下限/接近目标/高于上限）。
- 支持鼠标悬停显示详细信息。
- 自动旋转与仿真数据流演示。
- 异常脉冲动画提示。

## 6. 扩展与优化建议

- 后端可扩展为多用户/权限管理。
- 数据持久化可选 SQLite 或 MongoDB。
- 前端可增加参数配置、历史趋势图等功能。
- 支持导出/导入数据，便于培训与演示。

---

## 7. 总结

本方案适用于实验室参数监控、品质管理等场景，具备高扩展性与可视化交互体验。前后端分离架构便于维护与升级，可根据实际需求灵活调整。
